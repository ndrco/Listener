# Отключение Speaker Listener

Используйте этот навык, когда пользователь специально хочет, чтобы Listener прекратил
произносить ответы помощника вслух.

## Предпочтительная команда

Используйте встроенный скрипт `scripts/listener-speaker-off` (путь разрешается
относительно этого `SKILL.md`).

Пример:

```bash
scripts/listener-speaker-off
```

Скрипт делегирует выполнение существующему навыку `listener-control`, выключает
Speaker, а затем печатает `speaker status`, чтобы вы могли подтвердить результат.

## Сопоставление намерений

- Отключить голосовые ответы
- Отключить голосовой вывод
- Прекратить читать ответы вслух
- Не произносить ответы
- Отключить звук Listener TTS

После запуска помощника кратко сообщите, отключены ли голосовые ответы.
